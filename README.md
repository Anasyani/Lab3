## 📌 Описание задания

Использовать форму из ЛР-2, но обрабатывать данные на сервере через PHP: сохранять в сессию и в файл `data.txt`, выводить данные на странице, выполнять проверку корректности.

---

## ⚙️ Как запустить проект

```
git clone <ссылка на репозиторий>
cd lab3
docker compose up -d --build
```

- `http://localhost:8080/index.php` — главная (данные из сессии и ошибки)
- `http://localhost:8080/form.html` — форма
- `http://localhost:8080/view.php` — все сохранённые данные

Если на Linux файл `data.txt` не создаётся из-за прав доступа:

```
chmod 777 www
```

---

## 📂 Содержимое проекта

- `docker-compose.yml` — сервисы `nginx` и `php` (php:8.2-fpm)
- `nginx/default.conf` — конфиг Nginx с обработкой `.php` через PHP-FPM
- `www/form.html` — форма (`action="process.php" method="POST"`)
- `www/script.js` — только `alert` перед отправкой
- `www/process.php` — получение данных, проверка, сохранение в сессию и в `data.txt`
- `www/index.php` — вывод данных из сессии и сообщений об ошибках
- `www/view.php` — вывод всех записей из `data.txt`

---

## 🧪 Ход работы

1. **Форма для PHP.** Из JS убрана обработка (`preventDefault`, вывод на страницу), оставлен `alert`. В форме указаны `action="process.php"` и `method="POST"`.
2. **Сессии.** В `process.php` вызывается `session_start()`, данные из `$_POST` обрабатываются `htmlspecialchars` и сохраняются в `$_SESSION`, затем выполняется редирект на `index.php`.
3. **Вывод из сессии.** `index.php` показывает сохранённые данные или текст «Данных пока нет», а также ссылки на форму и `view.php`.
4. **Запись в файл.** Данные добавляются в `data.txt` через `file_put_contents(..., FILE_APPEND)`, файл создаётся автоматически.
5. **Просмотр всех данных.** `view.php` читает `data.txt` и выводит все записи списком.
6. **Проверка данных.** Имя не должно быть пустым, email проверяется через `filter_var(..., FILTER_VALIDATE_EMAIL)`, возраст — число от 16 до 100. При ошибках данные не сохраняются, сообщения передаются через `$_SESSION['errors']` и выводятся на главной.

---

## ✅ Результат

Форма обрабатывается на сервере через PHP, данные сохраняются в сессию и в файл, все записи отображаются на отдельной странице, некорректные данные отклоняются с сообщением об ошибке.
